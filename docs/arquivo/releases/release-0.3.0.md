# Lina 0.3.0 — Architectural Foundation & Improved User Experience

Lina 0.3.0 is a major stability update for multi-device vaults. It strengthens the foundation for semantic search and AI assistance while making everyday configuration clearer and easier to navigate.

## Smarter Producer and Companion Architecture

Lina now makes the responsibilities of each device clearer. The active Producer handles the heavier work of preparing and publishing search data, while Companion devices focus on using the information that has already been published. This helps keep multi-device workflows predictable without asking mobile or secondary devices to take on unnecessary background work.

## Improved Semantic Search Foundation

Semantic search and embeddings are managed more consistently across devices. Published search data is handled with stronger safeguards, so devices can use the same search foundation with greater confidence. When semantic search is not available on a Companion, Lina continues to provide local text search rather than presenting unreliable results.

## Better Configuration Boundaries

Lina now separates local device preferences from information shared across a vault more clearly. This reduces the risk of configuration conflicts between devices and makes it easier to understand which device is responsible for each task.

## Redesigned Settings Experience

Settings are now organised around how you use Lina: General, Search, AI Assistant & Analysis, Producer, Companion, Synchronization, Diagnostics, and Advanced.

AI, search, device roles, diagnostics, and technical options each have a clearer home. This reduces duplicated controls and keeps less common options out of the way until they are needed.

## More Reliable and Maintainable Architecture

Lina 0.3.0 preserves compatibility with existing user data while improving the reliability of its multi-device foundation. The result is a more stable base for future improvements without changing the way you work with your notes.

## Updating

Update through the Community Plugins flow when available, or replace the plugin files with the release assets. No manual configuration changes are required.
